Exercise 4 — Tiny RPC over Worker

Goal: wrap postMessage in a Promise-returning call(method, args) helper. Multiple in-flight calls must not get mixed up.

Protocol you'll design

Page → Worker:   { id, method, args }
Worker → Page:   { id, ok: true,  result }
                 { id, ok: false, error }
  1. In worker.js: implement two methods — add(a, b) (sync) and delayedHello(name, ms) (async). Reply with the right shape based on the request.
  2. In rpc.js: write createRpc(worker) returning { call(method, ...args) } where call returns a Promise that resolves with the result (or rejects with the error). Use a Map<id, {resolve, reject}> to correlate replies.
  3. In page.js: try add(2,3), delayedHello('alice', 1000), and a parallel Promise.all with multiple in-flight calls. Verify nothing crosses wires.
  4. Bonus: handle errors. Make worker throw on add('a','b') (when args aren't numbers) and confirm the page Promise rejects.
