Exercise 1 — Hello Worker

Goal: spawn a worker, send it "ping", log whatever it sends back. Verify the work happens off the main thread.

  1. In worker.js: register an onmessage handler. When you receive {type:'ping'}, send back {type:'pong', at: Date.now()}.
  2. In page.js: create the worker, hook up onmessage to render replies into #log, and wire the buttons.
  3. Block test: click "Block main thread 2s" while pings are flying. Notice the page freezes but the worker keeps replying.
