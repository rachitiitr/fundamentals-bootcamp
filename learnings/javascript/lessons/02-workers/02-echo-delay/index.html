Exercise 2 — Echo with Delay

Goal: the worker echoes back whatever you send it, but only after waiting delayMs milliseconds.

  1. In worker.js: when you receive {text, delayMs}, wait delayMs using setTimeout, then post back {echoed: text, after: delayMs}.
  2. In page.js: send the input text with a 1000ms delay. Append replies to log.
  3. Concurrency test: rapidly click "Send" 5 times. Notice all 5 replies come back roughly together after 1 second — proving the worker handled them concurrently (setTimeout doesn't block the worker thread either).
