Exercise 5 — Streaming Ticker via Worker

Goal: the worker hosts the WebSocket to Binance. The page subscribes to a symbol and consumes trades via an async generator. Multiple subscribers in the same page should share data nicely.

Protocol you'll design (extends the RPC shape)

Page → Worker:  { id, method:'subscribe', args:[symbol] }     // streaming start
                 { id, method:'unsubscribe' }                  // CANCEL

Worker → Page:  { id, type:'next',     value: trade }          // each tick
                { id, type:'complete' }                        // stream ended (e.g. WS closed)
                { id, type:'error',    error }                 // something broke
  1. In worker.js: open a single WebSocket per symbol on first subscribe. Track subscribers; close the WS when the last subscriber unsubscribes.
  2. In rpc.js: extend the previous helper with callStream(method, ...args) that returns an async generator. Cleanup (the finally) sends an "unsubscribe" message.
  3. In page.js: render the latest BTCUSDT price + a small list of last 10 trades. Use two SEPARATE callStreams (one for each component) and verify only ONE WebSocket exists in the worker (check console logs).
