Exercise 3 — Two Workers (Isolation)

Goal: spawn TWO instances of the SAME worker file. Prove they have independent state.

  1. The worker maintains a counter starting at 0. On each {type:'inc'}, increment and reply with new value.
  2. The page spawns workerA and workerB from the same worker.js.
  3. "Inc A" → only A's counter goes up. "Inc B" → only B's. Verify they're independent.
  4. Bonus: also try the "Read globals" buttons — each worker has its own copy of self, no shared memory.
